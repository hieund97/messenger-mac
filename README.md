# MacMess

Ứng dụng Messenger native cho macOS (SwiftUI + lõi Go nhúng qua cgo), giấy phép AGPL-3.0. Build: `make core`, `make kit-test`, `make app`. Khi thêm dependency messagix vào `core/go.mod`, chép version từ `spike/go.mod`.

Nội dung thông báo tin nhắn hiện trên màn hình khóa theo cài đặt "Show previews" của macOS.
